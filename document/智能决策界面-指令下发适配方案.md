# 智能决策界面 - 指令下发适配方案

## 背景

后端已实现 `POST /api/command` 指令下发接口，支持向 OneNet 平台下发设备期望属性值。当前前端 DecisionView 的设备控制面板是纯 UI 模拟（水泵开关、出水量等均为假数据），需要改造为调用真实 API。

## 可写属性

| 标识符 | 名称 | 类型 | 取值范围 |
|--------|------|------|---------|
| F | 水泵状态 | enum/int | 0=关闭, 1=开启 |
| I | PH阈值低 | string | 如 "5.5" |
| J | PH阈值高 | string | 如 "8.5" |
| K | 土壤湿度阈值低 | string | 如 "30" |
| L | 土壤湿度阈值高 | string | 如 "70" |

## 改动清单

### 1. `src/api/index.ts` — 新增 `sendCommand` API 函数

新增 `CommandResponse` 类型和 `sendCommand()` 函数，调用 `POST /api/command`。

### 2. `src/views/DecisionView.vue` — 设备控制面板改造

**移除：**
- 出水量滑块（waterVolume）
- 工作时长输入（waterDuration）
- 工作间隔输入（waterInterval）
- 允许时段选择（allowedStart/allowedEnd）

**新增：**
- 水泵开关 → 调用 `sendCommand("device", "F", 0/1)`，同时从实时数据读取水泵实际状态（F 的 enum_desc）
- 设备阈值下发区 — 4 个输入项，每个带「下发」按钮：
  - PH阈值低 (I)
  - PH阈值高 (J)
  - 土壤湿度阈值低 (K)
  - 土壤湿度阈值高 (L)

**保留：**
- 当前生效阈值卡片（中间卡片，显示 DB 阈值）
- 智能决策建议卡片（右侧卡片）

### 3. 交互说明

- 水泵开关切换时，调用 API 下发指令，成功/失败均通过 Toast 提示
- 阈值输入框失焦不清空，仅在点击「下发」按钮时发送
- 下发前显示确认提示，避免误操作
- 各输入框从实时数据中读取当前设备端阈值作为默认值
