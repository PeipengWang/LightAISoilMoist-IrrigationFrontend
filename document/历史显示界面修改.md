# 历史数据分析页面优化需求（仅包含指定4项优化内容）
## 优化1：多指标曲线值域差异问题，新增双Y轴能力【最高优先级】
### 问题描述
当前页面支持同时勾选多个监测属性绘制折线图，不同指标数值区间差距较大；以PH值（值域0~14）与土壤湿度（值域0~45）为例，图表仅提供单一Y坐标轴。
值域小的指标曲线视觉波动被严重压缩，指标变化无法直观观察，值域区间大的指标波动被过度放大，造成图表视觉失真，失去数据对比分析价值。

### 优化方案（方案A 双Y轴模式，推荐实现）
1. **坐标轴分配规则**
   - 默认：第一个选中指标绑定**左侧主Y轴**；后续选中指标自动绑定**右侧次Y轴**。
   - 图例颜色与对应坐标轴线条颜色保持一致，视觉关联。
   - 示例：PH值(0~14) → 左Y轴；土壤湿度(0~45) → 右Y轴。
2. **坐标轴自适应计算**
   左右Y轴不再使用固定区间，**根据当前查询时间段内指标最大、最小值自动扩展上下边界**，预留少量边距，曲线不会紧贴图表上下边缘。
3. **兼容单指标场景**
   当仅勾选**单个属性**时，自动隐藏右侧Y轴，仅展示左侧坐标轴，保持原有展示效果。
4. **交互约束**
   - 最多支持两组坐标轴（建议限制同时勾选指标数量≤2，避免3个及以上指标无法分配双轴引发新的视觉混乱）；
   - 曲线hover悬浮提示保持不变，统一展示全部指标对应时刻数值。

### 验收标准
同时勾选PH、土壤湿度后，两条曲线波动均可清晰观察，不会出现某一条曲线被压扁的失真现象。

## 优化2：X轴时间刻度拥挤重叠 & 完善Tooltip悬浮弹窗
### 问题描述
当查询时间跨度较长（如近7天），采集点数量较多时，X轴时间标签数量过多，文字横向挤压、互相重叠，无法直接读取时间；仅依靠静态图表难以精准获取每个采集点完整时间与指标数值。

### 优化方案
1. **X轴刻度动态自适应**
   前端根据**整体时间跨度、图表可视宽度**自动控制渲染刻度数量：
   - 时间跨度≤24h：刻度按小时展示；
   - 时间跨度>24h且≤7天：刻度按天+关键小时展示；
   - 时间跨度＞7天：刻度按日期展示；
     自动减少部分刻度标签，从根源避免文字重叠。
2. **Tooltip悬浮信息标准化**
   鼠标悬浮至曲线任意采集点时弹出悬浮框，固定展示内容：
    ```
    采集时间：2026-07-04 20:43:38
    PH值：7.8
    土壤湿度：45.0 %
    ```
   ✅要求：**展示完整年月日时分秒**，同时列出当前画面所有曲线对应的指标数值。
3. 可选增强：开启图表鼠标框选缩放功能，框选一段区间后图表自动放大，细化查看局部时段数据。

### 验收标准
无论选择近1天/近7天时间范围，X轴标签不再文字重叠；hover点位可一次性查看完整时间+全部指标数据。

## 优化3：缺失采集数据可视化优化
### 问题描述
传感器离线、上报失败时，明细表格数据展示为`--`；当前折线图直接断开线条，用户无法区分「数值为0」和「数据缺失未采集」两种业务场景，容易误判设备状态。

### 优化方案
1. **折线图断点样式区分**
   两个有效采集时间点之间存在缺失数据时：
   - 原有实线 → 改为**浅灰色虚线**连接两段有效数据；
   - 禁止直接空白切断折线，同时视觉区分正常连续数据与缺失区间。
2. **明细表格空值增强提示**
   表格单元格显示`--`保持不变；鼠标悬浮`--`单元格弹出提示文字：`该时刻传感器未上报采集数据（设备离线/信号异常）`。
3. 边界规则：连续缺失大量点位时，虚线不宜无限拉长，超过阈值可停止虚线连接，空白区域代表长时间断连。

### 验收标准
能够直观区分：正常采集数据、数据缺失空档；表格空值可悬浮查看缺失原因说明。

## 优化4：页面筛选栏自适应布局，解决窄屏横向溢出
### 问题描述
当前筛选组件（设备下拉、属性多选下拉、时间范围下拉、查询、重置按钮全部横向一排排布），当浏览器窗口缩小、笔记本小屏幕查看时，筛选栏组件横向超出页面容器，出现横向滚动条，体验较差。

### 优化方案
1. **布局规则：流式自动换行**
   筛选栏采用弹性布局`flex-wrap: wrap`：
   - 屏幕宽度充足：所有筛选组件保持同一行横向排列；
   - 浏览器宽度不足时，后续组件自动换行至第二行、第三行，**禁止横向溢出页面**。
2. **组件间距适配**
   换行后组件之间保持统一上下、左右间距，不能拥挤堆叠；
3. **最小宽度约束**
   下拉输入框设置合理最小宽度，不会被无限压缩导致内部文字无法阅读。
4. **整体对齐方式**
   组件换行后整体保持左对齐，和页面卡片内容保持统一边距。

### 验收标准
逐步缩小浏览器窗口宽度，筛选组件自动换行，页面不会产生水平滚动条，所有筛选按钮、下拉框完整可见。
